# Playwright 测试知识

本目录记录经过验证、可跨测试复用，但不能仅靠 Contract、产品事实或可执行资产充分表达的测试经验。按业务域或稳定主题创建 `{domain-or-topic}.md`，例如 `auth.md`、`outbound.md`、`table-interactions.md`；没有真实知识时不创建空主题文件。

可执行的定位器、导航和页面操作分别维护在 `pages/`、`components/`，知识文件只记录选择依据、适用条件、已知行为和失效边界。若一条经验已经能稳定实现为代码，应沉淀到 Page、Component、Action、Flow、Fixture 或 Utils，并在知识文件中保留必要的背景与资产链接，不复制实现。

每条知识使用以下结构：

```markdown
## K-PW-001 标题

- 适用范围：业务域、页面、组件或测试模式
- 已验证环境：环境名与部署版本；未知时明确写未知
- 证据：相关 Page/Component、产品源码或测试报告的仓库相对路径
- 结论：已验证的定位、交互、等待或诊断经验
- 使用方式：何时采用，如何判断成功
- 失效边界：不适用条件和需要重新验证的变化
- 最近验证：YYYY-MM-DD
```

适合记录：稳定导航入口、语义定位优先级、iframe/弹窗/表格等控件行为、保存后刷新规律、可靠等待信号、角色权限差异，以及多次复现的浏览器兼容或诊断经验。

不记录：一次失败猜测、测试用例专属步骤与断言、完整选择器实现、临时页面状态、账号密钥、Token、Cookie、Trace 内容或未经验证的推断。源码证据使用仓库相对路径，建议带行号；本地报告只记录可定位的相对路径，不复制敏感内容。
